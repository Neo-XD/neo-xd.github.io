04 — Release Notes

Release notes.

A concise history of major features, improvements, fixes, and known issues across Nocturne releases.

Nocturne Music — Desktop
v0.6.729 Aug 2026

Seamless remote device sync.

  • Added zero-PIN remote pairing with UDP discovery and direct WebSocket connections over local Wi-Fi or Tailscale.
  • Added a dedicated Output Devices sidebar for one-click switching between desktop and connected mobile devices.
  • Moved LAN host details into Settings and added masked local-IP display.
  • Added bidirectional playback handoff between desktop and phone, preserving the track, queue, and exact playback position.
  • Added real-time position, queue, and metadata synchronization.
  • Known issue: background reconnection may take 1–2 seconds after device sleep, and playback synchronization may still be unreliable.
v0.6.629 Aug 2026

Remote control, Discord presence & library sync.

  • Added an embedded remote playback server with secure PIN authentication and QR pairing.
  • Added official Discord Rich Presence with artwork, progress, artist metadata, and YouTube Music links.
  • Added Save to Library / Remove from Library through context menus, with YouTube Music account synchronization.
  • Added frosted-glass context menus for the Glassy theme.
  • Added independent animation-speed controls for Glassy and fullscreen-player backgrounds.
  • Polished playlist banner gradients and added floating navigation controls for overflowing tab bars.
  • Fixed CI/CD bundle discovery across Windows, Linux, and macOS packaging, and standardized Rust formatting.
v0.6.528 Aug 2026

Glassy visuals and performance controls.

  • Added the Glassy ambient theme with translucent frosted-glass panels and a real-time fluid GPU background.
  • Added detailed visual controls for Glassy and fullscreen backgrounds, including warping, brightness/opacity, blur and saturation, with reset buttons.
  • Added persistent floating tab bars with navigation arrows for Home and Library.
  • Added a Performance tab with low-spec controls, reduced transparency, reduced motion and performance profiles.
  • Added hardware-impact labels and an animated WebGL fullscreen/Glassy background.
  • Reworked the back-to-top control and home header, plus improved lyrics scrollbars and sidebar overflow protection.
  • Fixed fullscreen word-by-word lyrics visibility.
v0.6.427 Aug 2026

Nested library organization.

  • Added multi-level playlist folders with recursive nesting, collapsible trees, item counts and cycle prevention.
  • Added drag-and-drop playlist/folder organization and breadcrumb-based unfiling.
  • Added Save Queue to Playlist.
  • Added a customizable keyboard-shortcut manager and an explicit-content playback filter.
  • Added context menus to search results and quick folder creation in the sidebar.
  • Improved explicit-song indicators, inline playlist creation and subfolder navigation.
  • Hardened explicit metadata synchronization, lyrics-provider timeouts and folder cycle detection.
  • Note: the MSI is a single-version installer; the EXE installer should be used for auto-updates.
v0.6.327 Aug 2026

Folders, search and better lyrics.

  • Added playlist folders with artwork collage previews, creation/editing and batch assignment.
  • Added a sticky top search bar with typeahead suggestions and Ctrl+K focus.
  • Added customizable lyrics-provider priority and Better Lyrics integration with syllable/word-level karaoke sync.
  • Added customizable lyrics fonts, including support for local font files.
  • Enhanced fullscreen playback, lyrics controls, ambient glow and settings sizing.
  • Added instant window startup and merged upstream playback/library enhancements.
  • Fixed Windows MSVC linker conflicts, removed the Netease lyrics endpoint and corrected window-title synchronization.
  • Update note: uninstall the previous version through the NSIS installer without deleting application data.
v0.6.226 Aug 2026

Fullscreen controls and playback polish.

  • Added F11 borderless fullscreen player mode with ambient artwork and live lyrics.
  • Added expanded keyboard transport controls for play/pause, next/previous, shuffle, repeat and mute.
  • Added search inside the Add to Playlist dialog and a redesigned Ctrl+H shortcuts guide.
  • Refined fullscreen layout and controls, added blurred playlist heroes and pre-warmed music-video streams.
  • Improved persistent video surfaces and local AlbumArtist ID3 tagging.
  • Fixed shelf playback behavior, music-video A/V sync and black-screen flicker, hidden-window decoding continuity and duplicate changelog entries.
v0.6.125 Aug 2026

Last.fm authentication cleanup.

  • No new features or general improvements were listed.
  • Removed the Last.fm login popup.
  • Last.fm now requires users to provide the API key and shared secret manually.
v0.625 Aug 2026

The Nocturne rebrand & player foundation.

  • Added a dedicated fullscreen player with ambient artwork, live-synced karaoke lyrics, and keyboard controls.
  • Added a docked Now Playing / Info sidebar and a default monochrome theme.
  • Added coordinated sidebar visibility rules and fullscreen typography/layout polish.
  • Completed the internal rebrand to Nocturne, including package/app identifiers, database migration, MIME types, user-agent strings, update endpoints, and tray handlers.
  • Added NOCTURNE environment-variable support and updated changelog and upstream attribution.
  • Fixed lyric sidebar scrolling, lyric centering/reset behavior, and Last.fm build/runtime fallbacks.
v0.5.1125 Aug 2026

Quiet fixes & player polish.

  • Added matching context menus to home-page tiles and a new Spotify-like Now Playing sidebar.
  • Moved artwork-color crossfade handling to the browser for smoother track changes.
  • Fixed incorrect liked-song state, uploaded-track playback validation, and custom-font input lag.
  • Fixed video continuing to play after the mini player paused it.
  • Windows installers only; Linux users were directed to build for their distro.
  • This release is based on a fork of SimoHypers' Limusic.
Nocturne Mobile — Android
v0.129 Aug 2026

The first Nocturne Music release for Android.

  • Added zero-PIN remote discovery using UDP broadcast and WebSockets across local Wi-Fi and Tailscale.
  • Added full remote-controller mode for controlling desktop playback from Android.
  • Added bidirectional playback handoff between phone and desktop with exact timestamp continuation.
  • Added dynamic ambient player backgrounds: Gradient, Blur, Apple Music Fluid Blur, and Live Mesh.
  • Added synchronized Now Playing artwork, metadata, and live position with the desktop client.
  • Added a release-build fallback to debug signing when a release keystore is unavailable.
  • Cleaned up legacy settings branding and aligned Room migration schemas.
  • Known issue: remote playback state synchronization may intermittently lag or desynchronize when network interfaces change or Android resumes from background suspension.
